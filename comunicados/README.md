# Comunicados

Mensagens enviadas aos usuários a cada atualização do sistema (WhatsApp).

- Um arquivo por comunicado, no formato `AAAA-MM-DD_assunto-curto.md`.
- Cabeçalho com assunto, canal e público; a mensagem pronta para copiar fica depois da linha `---`.
- O histórico fica salvo pelo git (commit/push).
